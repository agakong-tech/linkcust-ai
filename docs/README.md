# LinkCust Documentation

LinkCust-specific architecture and product documentation lives here.

Recommended structure as documents are added:

- `architecture/` — current system architecture and subsystem designs.
- `adr/` — Architecture Decision Records, especially intentional divergences from Twenty upstream.
- `product/` — product concepts, domain models, and capability boundaries.
- `development/` — local development, testing, integration, and release guidance specific to LinkCust.

Do not copy Twenty documentation into this directory. Link to upstream documentation when the behavior remains unchanged.
